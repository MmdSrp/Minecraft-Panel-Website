## درباره پروژه

**کرفت‌ورس** یک پنل کاربری کامل برای سرورهای ماینکرافتی است که به‌صورت ۱۰۰٪ فرانت‌اند ساخته شده:
نه بک‌اند لازم دارد، نه دیتابیس، نه ابزار Build و نه نصب هیچ پکیجی — کافی است فایل `index.html` را باز کنید.

کل پروژه در **یک فایل HTML** پیاده‌سازی شده است: صفحه ورود/ثبت‌نام، داشبورد زنده، فروشگاه با فرآیند پرداخت، سیستم تیکت پشتیبانی و تنظیمات کامل — به‌همراه سیستم تم (خودکار/روشن/تاریک)، رنگ‌های لهجه و طراحی کاملاً ریسپانسیو و راست‌به‌چپ.

> نکته: این پروژه نسخه‌ی نمایشی است؛ داده‌ها شبیه‌سازی شده‌اند و پرداخت واقعی انجام نمی‌شود.

## شروع سریع

```bash
# کلون کردن ریپو
git clone https://github.com/MmdSrp/CraftVerse-Panel.git
cd CraftVerse-Panel

# روش ۱: فایل index.html را مستقیم در مرورگر باز کن — همین!

# روش ۲ (اختیاری): با سرور محلی
npx serve .
# یا
python -m http.server 8000
```

<details>
<summary><b>چطور تست کنم؟ (حساب دمو)</b></summary>

- هر **نام کاربری** (۳ تا ۱۶ حرف انگلیسی) + **رمز عبور** (حداقل ۴ کاراکتر) → وارد پنل می‌شوی
- یا روی دکمه «حساب دمو نداری؟ با یک کلیک وارد شو» در پایین فرم ورود بزن
- نشست در `localStorage` ذخیره می‌شود و در بازدید بعدی به‌صورت خودکار وارد می‌شوی
- برای خروج از دکمه «خروج» و برای ریست کامل در کنسول مرورگر `localStorage.clear()` بزن

</details>

## امکانات

### ۱) صفحه ورود و ثبت‌نام
- پس‌زمینه‌ی تعاملی **Canvas** با بلوک‌های ایزومتریک ماینکرافتی (چمن، سنگ، الماس، طلا، سرخ‌سنگ، بلوط)
- **بلوک‌ها با کلیک می‌شکنند** + ذرات خرده‌بلوک سه‌بعدی + افکت صوتی ۸ بیتی ساخته‌شده با WebAudio (بدون هیچ فایل صوتی)
- پارالاکس با حرکت موس + شناوری بلوک‌ها + ستاره‌های پیکسلی چشمک‌زن
- تب ورود / ثبت‌نام با **اعتبارسنجی کامل فارسی** (نام کاربری با Regex، ایمیل، تطابق رمزها، پذیرش قوانین)
- نمایش / مخفی‌کردن رمز عبور
- نوار وضعیت زنده‌ی سرور + **کپی IP با یک کلیک**
- ذخیره‌ی نشست و **ورود خودکار** در بازدید بعدی
- انیمیشن گذار نرم به پنل

### ۲) داشبورد
- نوار آمار زنده: بازیکنان آنلاین با **به‌روزرسانی هر ۳ ثانیه**، پینگ، آپ‌تایم، رکورد
- **نمودار تعاملی** فعالیت ۲۴ ساعته با Canvas + Tooltip روی هاور
- لیست دنیاهای سرور با نوار ظرفیت و دکمه ورود
- کارت پروفایل با **آواتار پیکسلی ۸×۸ تولیدشده الگوریتمی از روی نام کاربری** (رنگ پوست/مو/چشم بر اساس Hash نام)
- تایم‌لاین رویدادهای پیشِ رو + بخش اخبار سرور
- تمام اعداد به‌صورت فارسی

### ۳) فروشگاه
- **باندل ویژه هفتگی با شمارش معکوس زنده**
- رنک‌های VIP / MVP / LEGEND با لیست مزایا و تشخیص خودکار رنک فعلی کاربر
- انتخاب مدت رنک (ماهانه / ۳ ماهه / دائم) با تغییر قیمت لحظه‌ای
- کلیدهای صندوق و بسته‌های کوین
- **فرآیند خرید کامل**: جزئیات ← انتخاب درگاه (کیف پول با بررسی واقعی موجودی / زرین‌پال / درگاه بانکی) ← صفحه اتصال به درگاه ← رسید موفقیت با کد پیگیری
- خریدها **واقعاً روی حساب اعمال می‌شوند** (رنک، کوین، کلید) بدون رفرش صفحه

### ۴) پشتیبانی (تیکت)
- لیست تیکت‌ها با وضعیت (باز / در حال بررسی / بسته) و اولویت رنگی (کم / متوسط / بالا)
- رابط چت حبابی با آواتار و زمان‌بندی
- نشانگر «در حال نوشتن…» و **پاسخ خودکار پشتیبانی**
- ساخت تیکت جدید با اعتبارسنجی و انتخاب دسته و اولویت
- بستن تیکت + نشان تعداد تیکت‌های باز در منوی کناری

### ۵) تنظیمات
- تم **خودکار** (پیروی از سیستم‌عامل با `prefers-color-scheme`) / **روشن** / **تاریک** — با اعمال و ذخیره‌ی آنی
- **۴ رنگ لهجه** (سبز کریپر، کهربایی، یاقوتی، فیروزه‌ای)
- دکمه تغییر سریع تم در نوار بالا
- ویرایش پروفایل (نام نمایشی، بیو) و تغییر رمز عبور با اعتبارسنجی
- سوئیچ‌های اعلان + بخش خروج از حساب

### قابلیت‌های سراسری

| قابلیت | توضیح |
|---|---|
| تک‌فایلی | کل پروژه در یک `index.html` — بدون Build، بدون نصب پکیج |
| فرانت‌اند خالص | تمام منطق و داده‌ها سمت کاربر (شبیه‌سازی) |
| ریسپانسیو | منوی کشویی در موبایل، گرید تطبیقی، حالت موبایل تیکت‌ها |
| RTL | چیدمان کامل راست‌به‌چپ فارسی |
| ذخیره‌سازی | `localStorage` برای نشست، تم و رنگ لهجه |
| دسترس‌پذیری | پشتیبانی از `prefers-reduced-motion` |
| کامپوننت‌های سفارشی | سیستم توست، مودال و دراپ‌داون اختصاصی |

## بخش‌های این فرانت‌اند

این کد **۱۰۰٪ فرانت‌اند** است — هیچ بک‌اند، دیتابیس یا Build ندارد و با باز کردن `index.html` اجرا می‌شود. پنج بخش اصلی دارد:

1. **صفحه ورود/ثبت‌نام** — باکس وسط صفحه + پس‌زمینه بلوک‌های ایزومتریک تعاملی
2. **داشبورد** — آمار زنده، نمودار، دنیاها، پروفایل، رویدادها و اخبار
3. **فروشگاه** — رنک، کلید، کوین + فرآیند کامل پرداخت تا رسید
4. **پشتیبانی** — لیست تیکت‌ها + چت با پشتیبان
5. **تنظیمات** — تم، رنگ، پروفایل، رمز و اعلان‌ها

**چند نکته قبل از آپلود:**
- اسم ریپو `CraftVerse-Panel` را در لینک git clone و بج‌های Stars/Forks/Issues (که کامنت شده‌اند) با اسم واقعی ریپو خودت عوض کن
- اسکرین‌شات‌ها را در پوشه `screenshots/` بذار
- فایل `LICENSE` هم در ریشه ریپو بساز تا لینک مجوز کار کند
